# 简洁手机打卡应用

## 功能与界面

开发适配手机的网页应用，使用 Vue、TypeScript 和 Vite。采用简洁风格、浅色背景、大按钮和清晰的时间排版。

- **首页/打卡页**：显示本地日期、时钟、大号「打卡」按钮、本周累计工时。点击本周累计工时跳转到记录页。
- **记录页**：按周分组，按日期倒序展示记录，支持补卡、修改和删除。左上角有按钮跳转到设置页。
- **设置页**：新增、编辑、删除多组班段，每组包含一个签到范围和一个签退范围，输入精确到秒。

无需登录，设置和记录通过 `localStorage` 保存在当前浏览器；页面明确提示数据仅保存在本机。

## 打卡与统计规则

- 点击打卡时读取设备当前本地时间，保存到秒；任何时间都允许打卡，范围外记录保留但不参与统计。
- 每天可设置多组班段，每组取签到范围内最早一条、签退范围内最晚一条，直接相减，不扣午休。
- 缺少任一端，该组不计入工时并标记缺卡；其他完整班段照常计入。
- 当天工时为各完整班段之和；本周按本地日期的周一至周日汇总，以小时、分钟、秒展示，支持查看历史周。
- 修改范围、补卡、编辑或删除记录后，所有历史统计立即按当前设置重算。
- 首版支持同一天内的多组班段，不支持跨午夜班段。

## 数据与校验

- 记录保存唯一 ID、本地日期、`HH:mm:ss` 时间及来源（点击或手动），保留创建时的本地日期和时间，避免设备时区变化使历史记录移日。
- 设置保存带稳定 ID 的班段列表，各班段包含名称和上签退范围；本地存储带版本号。
- 范围起止均包含，所有上签退范围之间禁止重合，包括共享端点。例如连续设置应使用 `06:00:00–08:59:59`、`09:00:00–11:59:59`。
- 每组签到范围必须早于签退范围，范围起点不得晚于终点；保存前验证并显示具体冲突。
- 同一秒重复点击不新增记录；手动操作产生同秒重复时提示用户。补卡和修改禁止未来时间，删除前确认。
- 首次使用引导添加班段，未设置时仍可打卡，但不计算工时。存储失败时显示错误，不提示保存成功。
- 不增加后端接口；时间归类、配对和周汇总作为独立纯函数实现。代码使用四空格缩进，TypeScript 等适用语句以分号结束。

## 验证与验收

- 验证多班段累加、最早签到与最晚签退选择、缺卡不计入、范围外记录保留。
- 验证秒级起止边界、共享端点冲突、班段顺序和跨午夜设置拦截。
- 验证周一与周日归属、跨月和跨年周统计，以及历史周切换。
- 验证补卡、修改、删除和设置变更后重算，以及刷新后的数据恢复。
- 在手机宽度检查三个页面、表单和确认弹窗，确保没有横向滚动，主要按钮易于点击。
- 完成类型检查、生产构建和统计逻辑单元测试。
