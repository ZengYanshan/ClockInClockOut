# 打卡

适配手机的 Vue 3 + TypeScript 打卡应用，无需登录或后端。

## 启动

```sh
npm install
npm run dev
```

## 验证和构建

```sh
npm test
npm run build
```

构建产物位于 `dist`，可部署到静态网站服务器。开发服务器默认允许局域网访问，手机与电脑连接同一网络后可通过终端显示的 Network 地址打开。

## Android APK

已添加 Android 原生 WebView 容器，网页资源内置，支持离线运行。APK 内的数据与浏览器中的数据独立，卸载应用或清除应用数据会删除本机记录。

Windows 构建需要 JDK 17、Android SDK（Platform 35、Build Tools 34.0.0），在 `android/local.properties` 中配置 `sdk.dir`，或设置 `ANDROID_HOME`。然后执行：

```sh
npm run build:apk
```

产物为 `android/app/build/outputs/apk/debug/app-debug.apk`，是使用调试密钥签名的可安装测试包。正式上架时需另行配置发布签名。最低支持 Android 7.0，系统 WebView 需要支持现代网页功能（包括 `crypto.randomUUID`）。构建脚本会在打包前重新生成网页资源。

手机开启 USB 调试并连接电脑、授权调试后，在项目根目录执行以下命令安装 APK（需已将 adb 加入 PATH，且仅连接一台设备）：

```sh
adb install -r android/app/build/outputs/apk/debug/app-debug.apk
```

`-r` 表示覆盖安装并保留已有应用数据。

## 使用说明

- 首页点击圆形按钮打卡，时间使用设备本地时间，精确到秒。
- 点击本周工时查看记录，可切换历史周、补卡、修改与删除。
- 首页设置按钮进入班段设置，所有班段参与统计。未配置班段时预置上午（签到 06:00–10:30，签退 10:30–12:45）、下午（签到 12:45–15:30，签退 15:30–18:15）、晚上（签到 18:15–21:00，签退 21:00–次日 00:30）。已有非空配置保留。
- 每班段选签到范围最早记录与签退范围最晚记录，直接相减。缺卡不计入，范围外保留记录。同一秒不能重复记录。
- 范围禁止重叠，允许共用端点；交界秒归后一个范围，其余端点包含在内。签退结束时间支持跨午夜，凌晨签退计入前一天，周统计亦按班段所属日计算。
- 设置变更后全部历史工时按当前设置重算。
- 数据仅保存在当前浏览器 localStorage，清除网站数据会丢失记录。浏览器存储失败时会显示错误。

预置范围按用户提供的时间表配置，支持晚上跨日签退。
